Place test videos in the subdirectories:

  videos/normal/          — walking, standing, general activity
  videos/sitting/         — person sitting on chair/floor
  videos/lying/           — person intentionally lying down
  videos/bending/         — bending, picking objects up
  videos/exercise/        — yoga, stretching, floor exercises
  videos/fall_recovery/   — person falls but immediately stands up
  videos/fall_no_recovery/— person falls and remains down
  videos/occlusion/       — person partially hidden
  videos/multi_person/    — 2+ people in frame
  videos/poor_lighting/   — low light conditions

Label each video with a matching .csv file in the same directory.
See tools/label_format.md for the label format.
